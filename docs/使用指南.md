# 使用指南

> 面向拿到 `Twice1200-v0.1.0-win-x64.zip` 的人。
> 不需要懂 n2n、frp 或命令行,照着做就行。

---

## 一、这是什么

把两件事做成了一键操作:

| 功能 | 作用 | 适合 |
|---|---|---|
| **n2n 组网** | 让几台机器像插在同一根网线上(虚拟局域网) | 联机游戏、远程访问家里的电脑 |
| **frp 穿透** | 把本机某个端口开放到有公网 IP 的服务器上 | 让别人连你开的服务器 |

两者都需要一台**有公网 IP 的服务器**(通常叫"超级节点"或"frps"),这台服务器要由你们中间某个人准备。

---

## 二、系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11,**64 位** |
| .NET 运行时 | **不需要安装**——已打包在 exe 里 |

## 三、第一次使用:四步

### 第 1 步:解压

把 zip 解压到**一个固定位置**,例如:

```
D:\Tools\Twice1200\
```

> ⚠️ **不要**解压到 `C:\Program Files\` 或 `C:\Windows\` ——
> 那里需要管理员权限,程序会把数据写不进去。

### 第 2 步:双击 `Twice1200.exe`

会出现两个拦截提示,**都是正常的,不是病毒**:

**① 蓝色的"Windows 已保护你的电脑"**

点 **「更多信息」** → **「仍要运行」**

原因:这个程序没有购买代码签名证书。签名是每年几百到几千元的商业服务,个人项目通常没有。

**② 杀毒软件报警**

把程序加入信任(白名单)即可。

原因:包里带了 n2n 和 frp 的官方二进制文件。这两个是合法网络工具,但杀软的灰名单会误报——**全世界所有用它们的软件都会遇到,不是这个程序特有的**。

### 第 3 步:填写配置

切到 **「n2n 组网」** 页,填四个框:

| 框 | 填什么 | 从哪来 |
|---|---|---|
| **虚拟网卡名** | 保持默认 `n2n-TAP` | 不用改 |
| **网络组名** | 你们约定的组名 | **问组里的人** |
| **超级节点** | 例:`supernode.example.com:7777` | **问组里的人** |
| **本机虚拟 IP** | 例:`10.236.167.5` | **问组里的人**,每人不同 |
| **网络密码** | 你们约定的密码 | **问组里的人** |

**两个关键点:**

1. **组名和密码必须和组里所有人完全一致**,否则互相看不见。
2. **"本机虚拟 IP" 每个人必须不同**,但要在同一个网段里(前三段相同,最后一段不同)。

> 填完密码后**必须点「保存密码」** —— 密码单独存进本机凭据库,
> 不写进配置文件,这样配置文件可以随便分享或贴到聊天里。

### 第 4 步:连接

点 **「连接」**。看到这一行就成功了:

```
[OK] edge <<< ================ >>> supernode
```

## 四、怎么验证真的连上了

**不要只看有没有报错,要看这一行** `[OK] edge` —— 那是 n2n 自己确认的握手成功。

想确认能看见同伴,在 PowerShell 里:

```powershell
arp -a | Select-String "10.236.167"
```

能看到同伴的虚拟 IP(和它的 MAC 地址)就说明**二层已通**。

> **ping 不通不代表没连上。** Windows 防火墙默认拦截 ICMP,
> 但 ARP 能解析就说明数据链路是通的。**用 ARP 判断更可靠。**

## 五、常见问题

### 双击后没反应 / 一闪就退出

这是"单文件"版本,exe 首次启动会把自己解压到:

```
%TEMP%\.net\Twice1200\
```

如果那一步失败,程序会直接退出、**连窗口都不显示**。可以试:

1. 清空 `%TEMP%`(在文件管理器地址栏输入 `%TEMP%` 回车,全选删除)后重试
2. 重启电脑
3. 找分发者要「文件夹版」——那个版本启动时不需要解压

### 「准备环境」报错或弹 UAC

这是**唯一**需要管理员的操作(装 TAP 虚拟网卡驱动)。点「是」允许即可。

如果驱动装不上,可能是系统太新(随包的驱动是 2020 年的),把这行报错发给分发者。

### 连接成功但看不见同伴

按顺序检查:

1. **组名是否完全一致?**(大小写、空格都算)
2. **密码是否完全一致?**(可以用界面上的「指纹」核对)
3. **同伴的 edge 是否也在运行?**(他断开了你也看不见他)
4. 虚拟 IP 是否冲突?(两人填了同一个 IP)

### 虚拟 IP 冲突了怎么办

n2n 是二层网络,IP 冲突**无法自动检测**——两人的流量会互相干扰,表现为时通时断。只能靠约定:每人一个不同的尾号。

## 六、frp 穿透怎么用

「frp 穿透」页是把**本机的某个端口**开放到公网服务器上。

假设你在本机开了个 Minecraft 服务器(端口 25565):

| 框 | 填 |
|---|---|
| 服务端地址 | 你们那台公网服务器 IP |
| 控制端口 | 通常 `7000` |
| 鉴权 token | 问服务器管理者 |
| 端口映射:本地端口 | `25565` |
| 端口映射:服务端端口 | `25565`(可以从表里加多条规则) |
| 类型 | 游戏联机常见的是 `tcp`;有些游戏要 `udp` |

填完 → 点「保存 token」→ 点「启动映射」。

日志里出现这两行就成功了:

```
login to server success
start proxy success
```

之后别人用 `服务器IP:25565` 就能连到你的机器。

> **注意:** 服务器的**云安全组**也要放行这个端口,否则外面还是连不上。
> 这一步在云厂商控制台做,程序管不到。

## 七、你的数据存在哪

```
%APPDATA%\Twice1200\config.json    配置(不含密码,可以分享)
%APPDATA%\Twice1200\secrets.dat    密码,DPAPI 加密
```

`secrets.dat` 只能用**当前 Windows 账户**解开。所以:

- **换电脑要重新输密码**——这是设计如此
- 备份 `secrets.dat` 到别的电脑上**没有用**

---

## 八、需要知道的几件事

**① 这是一个二层网络。**

进去的人等于插在同一根交换机上,能看到彼此的广播流量和未加密的局域网服务。**只加信得过的人。**

**② 组名 + 密码就是唯一的门钥匙。**

没有账号体系。谁拿到这两个值就能进来。

**③ 程序没有代码签名。**

所以 Windows 和杀软会一直提示。这是个人项目的常态。

**④ 第三方组件有各自的许可证。**

n2n 是 GPL-3.0,frp 是 Apache-2.0,TAP 驱动是 GPLv2。
如果你要二次分发这个包,请保留 `assets\` 里对应的 LICENSE 文件。详见 `LICENSE`。
