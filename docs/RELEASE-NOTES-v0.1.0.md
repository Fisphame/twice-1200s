首个可用版本。把原本需要手工敲命令的 n2n 组网与 frp 端口映射做成了图形界面,
并修掉了原方案的明文密钥问题。

## 下载

| 文件 | 说明 |
|---|---|
| `Twice1200-v0.1.0-win-x64.zip` | Windows 10/11 64 位,**不需要安装 .NET** |

解压到任意可写目录(不要放 `C:\Program Files\`),双击 `Twice1200.exe` 即可。

**使用说明见包内 `使用说明.txt`,或仓库的 [docs/使用指南.md](docs/使用指南.md)。**

## 这个版本能做什么

**n2n 组网** —— 让几台机器像插在同一根网线上。

- 填超级节点、组名、密码、本机虚拟 IP,点「连接」
- **本机自测**:在自己机器上起一个临时超级节点并连它,完全不依赖外部服务器 ——
  用来快速判断"是我这边的问题还是服务器的问题"
- 21 项环境体检:权限、TAP 网卡、资源文件、DNS、连通性一次看全

**frp 穿透** —— 把本机端口开放到有公网 IP 的服务器上。

- 支持多条映射规则(表格增删),类型支持 `tcp` 与 `udp`
- 预览配置时可核对将要生成的 TOML
- **token 绝不进命令行** —— 只写进临时配置文件,进程启动后立即删除

- Windows 10 / 11,**x64**

## 首次运行的提示是正常的

程序**没有代码签名**,所以:

- Windows SmartScreen 会显示"未知发布者" → 点「更多信息」→「仍要运行」
- 杀毒软件可能报警 → 包内含 n2n 与 frp 的官方二进制,属于灰名单误杀

## 已知问题

- **单文件版本首次启动会解压到 `%TEMP%\.net\Twice1200\`**,该目录不可写时程序会直接退出且不显示窗口。
  可清空 `%TEMP%` 后重试;仍然不行时需要「文件夹版」(用 `package.ps1 -FolderMode` 重新打包)。
  包内 `使用说明.txt` 有这一节。
- 虚拟 IP 冲突无法自动检测(n2n 是二层网络,防火墙不回 ping、离线同伴扫不到)。
- TAP 驱动是 2020 年的 9.21.2 版本,在很新的 Windows 11 上可能装不上。
- 同时只能连一个 n2n 网络;frp 暂不支持 `http`/`https`/`stcp` 等需要域名或访问者配置的类型。

## 安全说明

- 密钥**不落明文**:DPAPI 加密,作用域为当前用户
- 密钥**不进命令行**:n2n 走环境变量,frp 走临时配置文件(启动后即删除)
- 日志**只抹显式声明的密钥**,不做猜测式脱敏(过度脱敏会让日志失去排查价值)
- 程序**不含任何预置的服务器地址**——默认值一律是 `.invalid` 这类保留域名,避免用户误连到陌生服务器

**这是二层网络工具。** 同一网络内的成员能看到彼此的广播流量与未加密的局域网服务,
只应加入信得过的人。
